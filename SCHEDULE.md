## Decision rules

If no real LLM backend works in block 1, record the blocker immediately and reduce setup scope. Do not spend the project building an inference platform or label prerecorded responses as live operation.

At hour 13, remove unreliable families from the release target if necessary. At hour 24, remove interface extras before weakening evaluation. At hour 26, document the supported set and actual evaluation counts. After the held-out test begins, retain all failures; fixes require a clearly labeled new version and fresh evaluation cases for new confirmatory claims.

The user authorized implementing the plan, including a public experimental source release after the gates pass. Existing presentation automations prepare drafts separately; implementation does not authorize unrelated outreach or portfolio deployment.
